# dsh-running-sessions

正在运行的会话，收进 DeepSeek Harness 窗口顶部的一条实时状态栏。

## 它做什么

- **是一条状态栏，不是又一张卡片。** 插件占用对话头部标题行左侧的常驻位置；只要它在，头部就
  变成两行——第一行状态栏，第二行会话标题和控件——状态栏和标题不再抢宽度，输入框上方也不占
  空间。状态栏消失时头部自动回到原来的单行。
- **直接列出是哪些会话，而不只是一个数字。** 状态栏开头是「5 个会话进行中」，后面跟着最
  活跃的会话胶囊；点一下就直接打开那个会话，效果和点左侧栏一样。胶囊数量是量出来的，不是
  写死的：按整行可用宽度尽量多放，窗口缩放会重新量。
- **「在等你」一眼可见。** 等批准、等确认计划、等回答的会话保持琥珀色圆点和对应状态文字，
  并排在只是「运行中」的会话前面；计数本身也会变成琥珀色并补上数字——
  `5 个会话进行中 · 2 个等你`——所以窗口窄到放不下胶囊时，这个信息也不会丢。子任务算在父
  会话行上，不冒充独立会话。
- **跑完了也不会丢。** 你还没打开过的「刚跑完」会话会以绿色圆点收进弹层的「刚刚完成」分组，
  状态栏里也有一段绿色计数。**不管从哪里打开都算看过**——弹层、左侧栏都一样：主视图一打开它，
  插件就记为已读，再切走也不会重新冒出来；只有下一次重新跑完才会再次提醒。如果一个在跑的都没有、
  只有刚完成的，状态栏只显示那段绿色数字。
- **当前会话有标记。** 你正在看的那个会话在列表里带「当前」标签，胶囊上有一圈细边框，标题
  相近时也不会认错。
- **完整列表一键展开。** 放不下的会话收成「还有 N 个」；点计数按钮会在**打开它的那个控件**
  下方弹出完整列表——标题、工作区、实时状态、运行中的子任务、刚刚完成——靠近窗口右缘时自动
  右对齐，按 Esc 或点空白处关闭。
- **实时，但不吵。** 直接订阅客户端会话目录与统一状态存储，并且按「语义」比对投影（运行中 +
  刚刚完成）：某个会话只是追加了一条事件时不会重渲染顶栏。开始、结束、进入「等你处理」都会
  就地更新，没有任何轮询。
- **空闲时完全消失。** 没有运行中的会话、也没有未读的完成提醒时，状态栏不出现，也不预留高度。

## 它在哪里

```
┌ 对话头部 ─────────────────────────────────────────────────────────────┐
│ ● 5 个会话进行中 · 2 个等你 ⌄  ● 会话甲  ● 会话乙  ● 会话丙  还有 2 个  │
│ 会话标题                                       标准模式      …    □     │
└────────────────────────────────────────────────────────────────────────┘
```

标题行里唯一「常驻且不受会话限制」的位置就是头部左侧座（`conversation.header.leading`），
所以它在主页（空白新会话）也显示——那里会话自己的头部装饰（标题、模式、视图标签）本来
就是隐藏的。插件样式表在状态栏挂载时把这个座提升为整行，状态栏消失后又退回原来的单行布局。

## 配置

无。装上即用，有会话在跑就出现。

## 实现

| 文件 | 职责 |
| --- | --- |
| `index.js` | 宿主端：只声明插件入口；这个功能不需要宿主计算任何东西。 |
| `client.js` | 浏览器端：目录投影、实时 store、头部状态栏、弹出列表、样式。 |

浏览器端只读三份客户端事实：

- `sessions.list` —— 实时会话目录。每行带 `running`、`blank`、`origin`、`updatedAt`、`cwd`、
  `retainedBy.mainView`（正在屏幕上的那个会话）以及子会话目录投影。
- `uiSession.sessionStatus` —— `running`、待处理交互类型（`approval`、`plan-review`、
  `question`），以及未读的 `completionUnread`。
- `workspaces.list` —— 只用来把行标上工作区名称，取不到时退回目录名。

`deriveRunning` 过滤掉空白会话（主页自己）与子会话行，把「等你处理」的排在前面，其余按「第一次
看到它在运行」的顺序排，这样会话不断写事件时胶囊也不会来回跳；`deriveCompleted` 收集未读的完成
记录，最新在前，最多六条。正在运行的子任务通过父会话的 `subagentCatalog` 统计，当前会话由
`retainedBy.mainView` 判定。一个外部 store 合并两个订阅源，每次先按语义比对新旧投影（运行中 +
刚刚完成），真的变了才唤醒 React——只追加事件不会改变数组引用。胶囊数量按实测宽度拟合
`min(72vw, 1200px)` 减去实测的计数按钮宽度，只有放不下时才为「还有 N 个」预留位置。弹层锚定在
打开它的控件下方，靠近窗口右缘时改为右对齐。点击行通过 `ctx.uiWorkspace.openSession` 打开——
和左侧栏点击走同一条导航。

### 开发

```bash
pnpm add -D jsdom react react-dom
node test/client.dom.test.mjs
```

DOM 测试在 jsdom 里跑真实的 `client.js`，用假的模块加载器、会话目录和状态存储驱动组件，
覆盖排序、过滤、胶囊、溢出、「等你」汇总、当前会话标记、刚刚完成分组、弹出列表、弹层锚定、
Esc 与外部点击关闭、打开会话、实时更新、子任务计数、胶囊宽度拟合、无需通知时不通知，以及空闲隐藏。
